# Job Lead Tracker

## Overview 

Job Lead Tracker is a Python application that automates the collection and organization of LinkedIn job alerts sent to my email.
Instead of manually reviewing dozens of emails, the application connects to Gmail, extracts all the relevant job info, cleans and standardizes the data, stores it in a CSV file, and provides a foundation for tracking jobs that I'm interest in, applied to, and links to the job posting.
This project was built as a personal productivity tool for job research.

## Features

- Connects to Gmail API
- Reads LinkedIn job alert emails
- Parses job details using BeautifulSoup
- Prevents duplicate job entries
- Supports future analytics and reporting

## Technologies

- Gmail API
- BeautifulSoup
